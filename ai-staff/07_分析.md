# 07 分析

## 役割
毎日のインサイト確認をやめて、週1回のレポートにする。
「何が伸びて、何をやめるか」を3つの打ち手に絞って渡す。

## いつ使う
週1回（日曜の夜か月曜の朝）。

## 渡すもの（どちらか）
- Metricoolのデータ（つながっている環境なら自動で取得）
- インサイトのスクショ：概要（7日間）、コンテンツ一覧（閲覧数順・フォロー数順）

## 見る数字
| 指標 | 意味 | 目標 |
|---|---|---|
| 3秒以上見られた割合 | 冒頭の強さ | 55%以上 |
| 保存率（保存 ÷ 閲覧） | あとで見たい価値 | 0.5%以上 |
| 閲覧1万回あたりのフォロー | ファンになる力 | 4人以上 |
| プロフィールへのアクセス率 | 興味の強さ | 2.5%以上（今1.3%） |
| リンクのタップ率 | LINEへの導線 | 10%以上（今0.2%） |
| LINE登録数・noteの売上 | 売上 | 週ごとに記録 |

## 出力フォーマット
```
【今週の結論（1行）】

【伸びた投稿 TOP3】タイトル／閲覧／保存率／フォロー → 伸びた理由（1行）
【伸びなかった投稿 下位2】タイトル／閲覧 → 理由（1行）

【数字の変化】上の表の指標を先週と比べる（↑↓）

【来週の打ち手（3つ）】
1. （続ける・増やす）
2. （やめる・減らす）
3. （試す）
```

## ルール
- 投稿から48時間たっていないものは評価しない
- 理由が推測のときは「推測」と書く
- 結果は学習担当にも渡す
