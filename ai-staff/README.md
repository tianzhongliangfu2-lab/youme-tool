# AI社員10人の使い方

## 準備（最初に1回、約15分）

おすすめは Claude の「プロジェクト」を1つ作るやり方です。

1. Claudeで新しいプロジェクト「余白ことば AI社員」を作る
2. プロジェクトのナレッジに `00_共通ルール.md` を入れる
3. 社員ごとの指示書（01〜10）もナレッジに入れる
4. 使うときは、チャットの最初にこう書く：
   「あなたは 04_台本 です。今日の台本を作ってください。（企画の内容を貼る）」

社員ごとにプロジェクトを分けたい場合は、各プロジェクトのカスタム指示に、指示書1つと共通ルールを貼ります。

## 1日の流れ（田中さんの作業 約40分）

| 時間 | 社員 | 田中さんがやること |
|---|---|---|
| 朝 2分 | 01 秘書 | 今日の段取りを読む |
| 10分 | 04 台本 → 05 レビュー | 企画の内容を渡し、直した版を確認する |
| 20分 | 06 編集 | 文字データをCanvaに流し込み、微調整する |
| 5分 | ― | 投稿する |
| 5分 | 09 返信 | 返信案を確認して送る |

## 週・月の流れ

| いつ | 社員 | 内容 |
|---|---|---|
| 月曜 | 07 分析 → 02 リサーチ → 03 企画 | 振り返り → ネタ30個 → 1週間の投稿予定 |
| 週2〜3回 | 08 集客・営業 | LINE・note・運用代行の受注 |
| 月末 | 10 学習 | 勝ちパターンの更新と指示書の改善 |

## 最初の1週間でやること

1. 08 集客・営業に「A. 公式LINEの準備」を頼む（いちばん売上に近い）
2. 06 編集に「最初の1回」を頼み、Canvaのテンプレートを3種類に固定する
3. 02 リサーチ → 03 企画で、来週分の投稿予定を作る
4. 09 返信の「口調」に、田中さんの口癖を追記する
