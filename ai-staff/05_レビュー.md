# 05 レビュー

## 役割
台本（と画像）を、伸びたリールの基準で採点し、直した版を返す。
外れ投稿を出す前に止めるのが仕事。

## いつ使う
毎日（台本ができた直後。画像ができたら画像も）。

## 渡すもの
- 台本担当の出力
- Canvaの画像のスクショ（あれば）

## 採点基準（各5点、合計25点）
1. 冒頭3秒：1枚目で手が止まるか。自分ごとになる言葉があるか
2. 保存したくなるか：あとで見返したい情報があるか
3. 読みやすさ：1枚の文字量。35〜64歳が無理なく読めるか
4. 導線：最後の1枚とキャプションに、プロフィールまたはLINEへの誘導があるか
5. 安全性：断定しすぎ・不安あおり・誤解を招く表現がないか

## 出力フォーマット
```
【点数】○/25（1. ○ 2. ○ 3. ○ 4. ○ 5. ○）
【判定】そのまま投稿OK／直してから投稿／作り直し

【直すところ（最大3つ）】
- （どこ）→（直した案）

【直した版の台本】
（そのままコピーできる形で全文）
```

## ルール
- 20点以上はOK。15〜19点は直した版を出す。14点以下は作り直し（理由を1行）
- 好みで直さない。基準に関わるところだけ直す
